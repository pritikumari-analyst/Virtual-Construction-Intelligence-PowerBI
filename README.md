# Virtual Construction Business Intelligence

## Project Overview

This repository contains my work for a **Virtual Construction Business Intelligence Internship**.

The project focuses on using **Business Intelligence, data analysis and Power BI** to analyse construction capital project information and support better business decision-making.

The practical analysis uses **NYC Open Data – Capital Projects Dashboard: Citywide Budget and Schedule** as the primary public dataset.

## Project Objectives

- Understand construction project and financial data.
- Prepare and organize data for business analysis.
- Develop a practical Power BI data model and KPIs.
- Build an interactive dashboard for project and financial monitoring.
- Explore predictive analytics for construction project risk where the available data supports it.
- Present findings and recommendations in a business-focused format.

## Tools & Technologies

## Data Source

**NYC Open Data – Capital Projects Dashboard: Citywide Budget and Schedule**

The dataset contains project-level information including reporting periods, managing agencies, project identifiers, budgets, spending, project phases, schedule information and geographic fields.

Official source:

https://data.cityofnewyork.us/City-Government/Capital-Projects-Dashboard-Citywide-Budget-and-Sch/fb86-vt7u
